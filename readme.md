# Credit Card Fraud Detection

End-to-end project using **SQL, Python, Excel, Power BI, GitHub**.

## Objectives
- Detect fraudulent transactions from credit card dataset.
- Explore data imbalance and fraud patterns.
- Build baseline ML model for fraud detection.
- Create reports (Excel) and dashboards (Power BI).

## Tools
SQL, Python (pandas, sklearn), Excel, Power BI, GitHub
